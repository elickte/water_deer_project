# 고라니 키우기

웹 응용 SW 프로그래밍 실무 팀 프로젝트

인간들이 숲을 개발하면서 먹을 게 없어진 고라니가 열매를 모으고 동료들을 모아서 숲을 지키는 방치형 클리커 게임이다.
HTML, CSS, JavaScript만 써서 만들었고 따로 라이브러리는 안 썼다. 고라니 움직이는 부분만 WebGL로 했다.

## 실행 방법

설치할 건 없다.

1. 레포를 받는다. (Code > Download ZIP 하고 압축 풀거나 git clone)
   ```
   git clone https://github.com/elickte/water_deer_project.git
   ```
2. `main.html`을 크롬이나 엣지로 열면 된다.

VS Code에 Live Server 확장이 있으면 `main.html` 우클릭 > Open with Live Server로 여는 게 제일 편하다.

참고

- 크롬, 엣지에서 테스트했다. (WebGL 되는 브라우저여야 함)
- 첫 번째 맵 배경이랑 설정 아이콘은 인터넷 이미지라서 인터넷이 끊겨 있으면 기본 숲 그림으로 나온다.

## 테스트 계정

로그인 기능이 없어서 테스트 계정은 따로 없다. 열면 바로 시작되고 진행 상황은 브라우저에 자동으로 저장된다.

후반 내용을 빨리 보고 싶으면 아래 키를 쓰면 된다.

- `D` : 열매 9,999,999개
- `F` : 레벨 크게 올리기 (맵, 스킨 다 열리고 맵 해금 컷씬이랑 엔딩까지 볼 수 있음)

처음부터 다시 하려면 설정 > 데이터 초기화 (한 번 더 물어봄)
설정 > 세이브 데이터 내보내기로 json 파일을 받아두고, 불러오기로 그 파일을 고르면 그 상태로 돌아간다.

## 조작

- 고라니 클릭 : 열매 획득. 가끔 크리티컬(2배)이 뜨고 야구선수 고라니가 있으면 홈런(10배)도 나온다.
- 아래 탭 버튼(강화, 동료, 펫, 스킨, 맵, 상점) : 누르면 창이 열리고 한 번 더 누르면 닫힌다.
- 강화, 동료 버튼은 꾹 누르고 있으면 계속 산다.
- 컷씬은 화면을 누르면 다음 대사로 넘어가고 건너뛰기 버튼도 있다.

## 기능

기획서에 있던 기능

1. 클릭으로 열매 얻기 (클릭 이펙트)
2. 고라니 강화 (만렙 800)
3. 동료, 펫 구매
   - 동료 12마리. 영입하고 나서 레벨업할 수 있고 10레벨마다 효과가 2배가 된다.
   - 펫 10마리. 클릭 열매나 초당 열매를 %로 올려준다.
4. 방치 시스템 (setInterval로 초당 열매 들어옴)
5. 스킨 8개. 조건 달성하면 열리고 적용하면 고라니 그림이 바뀐다.
6. 맵 해금 : 숲 > 하늘 위(Lv.100) > 개발 지역(Lv.300) > 인간 도시(Lv.500) > 숲 깊은 곳(Lv.800)
7. localStorage 자동 저장 (5초마다, 창 닫을 때)
8. 세이브 데이터 json 내보내기 / 불러오기
9. 데이터 초기화

추가로 넣은 것

- 컷씬 스토리 (인트로, 동료 처음 영입할 때, 맵 열릴 때, 엔딩)
- 오프라인 보상 : 게임 꺼놓은 시간만큼 열매를 준다. 최대 8시간까지고 잠자는고라니 레벨이 높으면 더 준다.
- 상점 부스터 : 2배는 처음부터, 100배는 Lv.150부터. 30초 동안 유지된다.
- 고라니가 숨 쉬고 클릭하면 고개를 꾸벅하고 꼬리를 흔든다. (그림 한 장을 WebGL로 움직임)
- 영입한 동료들이 메인 화면 뒤에 같이 서 있다.

## 파일 구조

```
main.html      화면, CSS
main.js        게임 로직 (데이터, 계산, 저장, 화면 갱신)
story.js       컷씬 대사, 컷씬 기능
deer-move.js   고라니 움직임 (WebGL)
skins.js       스킨 그림 데이터
deer.png       고라니 그림
assets/
  chars/       동료 그림
  maps/        맵 배경
  skins/       스킨 원본 그림
  story/       컷씬 그림
```

## 환경 변수

서버나 API 키, DB를 안 써서 필요한 환경 변수는 없다. 제출 형식 때문에 `.env.example`만 넣어뒀다.
